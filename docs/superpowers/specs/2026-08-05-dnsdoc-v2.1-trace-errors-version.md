# dnsdoc v2.1 — trace detail, query-error analysis, version display (design)

User feedback driving this round: the delegation trace hides NS names/IPs
("delegated to 7 NS" is useless for troubleshooting); query failures need
probable-cause analysis (REFUSED why, timeout why); authoritative checks
should note they query without recursion; the TUI must show its version and
GitHub repo. Detail-rich output beats summaries throughout.

## T6 — Full referral detail in the trace (`src/types.rs`, `src/checks/trace.rs`, `src/ui.rs`)

`TraceHop` gains `pub ns: Vec<String>` — the complete referral NS set for the
hop. `trace::run` collects every NS name from the referral and pairs it with
its glue A record when present in additionals: entries formatted
`"ns01.trs-dns.com. (64.96.1.1)"` with glue, bare `"ns01.trs-dns.com."`
without. `draw_trace` renders, under each hop line, one dim indented line per
NS entry (prefix `•`), aligned beneath the hop's glyph indentation. Scrolling
already handles the extra height.

## T7 — Response-code capture + probable-cause analysis + RD=0 (`src/dns.rs`, `src/checks/analysis.rs`, `src/checks/audit.rs`, `src/ui.rs`)

Today `dns::query` only reports transport errors ("timeout"); REFUSED /
SERVFAIL / NXDOMAIN arrive as Ok with empty answers and render as "(empty)".

- `dns::query`: when the response's `response_code() != NoError`, set
  `error = Some(code)` with the code normalized to upper-case DNS convention
  (`REFUSED`, `SERVFAIL`, `NXDOMAIN`, `NOTIMP`, `FORMERR`, else the hickory
  Display string upper-cased).
- New `dns::raw_query_opts(server, domain, rtype, rd: bool)` — builds the
  query message with `recursion_desired(rd)` and sends it; `raw_query`
  becomes a thin `rd = true` wrapper. Callers that talk to authoritative
  servers switch to `rd = false`: audit's SOA-serial fetch, lame-server
  check, AXFR probe, and the trace's NS queries.
- New pure `pub fn explain_error(err: &str) -> Option<&'static str>` in
  `src/checks/analysis.rs`, case-insensitive contains-match:
  - timeout → `"no response — server down, port 53 filtered, or rate limiting"`
  - REFUSED → `"server declines this query — not authoritative for the zone, query ACL, or recursion denied"`
  - SERVFAIL → `"server-side failure — DNSSEC validation failure, lame delegation, or broken upstream"`
  - NXDOMAIN → `"name does not exist here — stale negative cache or split-horizon view"`
  - NOTIMP → `"server does not implement this query type"`
  - anything else → None
- `analyze_propagation`: errored rows are grouped by error kind; each group
  contributes one evidence line
  `"{n} resolver(s) {KIND} ({names}) — {explanation}"`.
- Propagation table: error cell text stays the raw code, colored red for
  rcode errors, DarkGray for timeouts.
- Audit SOA-serial and lame-server details append `" [RD=0, no recursion]"`
  so it is explicit these were non-recursive authoritative queries.

## T8 — Version + repo in the TUI (`Cargo.toml`, `src/ui.rs`)

- `Cargo.toml`: `version = "0.2.0"`, add
  `repository = "https://github.com/barun-labs/dnsdoc"`.
- Header title becomes
  ` dnsdoc v{CARGO_PKG_VERSION} — {domain} · [{profile}] `.
- Help overlay gains a bottom line with `env!("CARGO_PKG_REPOSITORY")`
  (dim), and the overlay height grows to fit.
