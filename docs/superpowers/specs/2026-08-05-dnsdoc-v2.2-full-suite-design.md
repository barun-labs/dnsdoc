# dnsdoc v2.2 — full analyzer suite (design)

User approved ALL suggestions from the v2.1 round ("do all, then merge and
deploy"). Thirteen features. Still TUI-only. No new crates — the only
allowance is enabling a hickory-proto cargo *feature* if typed DNSSEC records
require it. MTA-STS policy *body* (HTTPS) is out of scope; its DNS record is
in.

## Tab layout change

`Tab::ALL` grows to eight: Propagation, Audit, Trace, Dnssec, Mail, Sweep,
Monitor, Analysis — keys `1`–`8`, same Tab/arrows cycling. New tabs run
their checks on first visit / `r` like existing ones. `spawn_all` keeps
fanning out propagation+audit+trace (Analysis unchanged); DNSSEC/Mail/Sweep
fetch on their own tab action.

## Features

### F1 — RRSIG expiry watch (DNSSEC tab)
For the domain: query RRSIG for A/AAAA/MX/TXT/SOA/DNSKEY at an authoritative
NS (RD=0, EDNS DO=1 so signatures are returned). Per signature: type covered,
algorithm, key tag, expiry timestamp, and a countdown (`expires in 12d` /
`EXPIRED 3h ago`). Severity: Err when expired, Warn < 7 days, else Ok.
Pure countdown/severity fn takes `now` for tests.

### F2 — Resolver validation matrix (DNSSEC tab)
Query the domain (A) against every resolver in the active profile with EDNS
DO=1. Record per resolver: AD flag (validated), rcode, latency. Matrix rows
`resolver — AD ✓/✗ — rcode`. Summary line: "N of M resolvers validate".

### F3 — TCP + EDNS probe (Audit tab)
Per authoritative NS: same SOA query over TCP (RD=0). Check: TCP answers?
EDNS supported (OPT record echoed, buffer size)? TC bit on UDP answer?
Checks: `TCP transport` (Err when any NS refuses TCP — "large responses and
zone transfers will fail; TCP/53 filtered?"), `EDNS` (Warn when unsupported,
report buffer size when present).

### F4 — Glue consistency (Audit tab)
For each in-bailiwick NS name: parent-side glue A (from the TLD referral —
reuse a trace-style NS query at the parent zone's server) vs the child zone's
own A answer. Mismatch → Err naming both IPs. Out-of-bailiwick NS → skip.

### F5 — CNAME chain tracer (Audit tab)
Follow CNAME from the domain (and `www.`): chain of targets until terminal
A/AAAA or dead end. Err on loop or dangling target, Warn when length > 8
(resolver give-up territory), Ok otherwise with the chain in the detail
(`a → b → c (2 hops)`). Pure chain-walk logic over a fetched map, testable.

### F6 — DNSSEC chain detail (DNSSEC tab)
Per zone cut (reuse trace's zone list): DS RRset at the parent, DNSKEY RRset
at the child; match DS key tags against DNSKEY key tags — flag DS pointing at
absent keys. List algorithm numbers with names; flag deprecated (1 RSAMD5,
3 DSA, 5 RSASHA1, 6/7 SHA1-NSEC3) as Warn. Uses typed DNSSEC rdata
(hickory `key_tag()`); enabling a hickory-proto feature for the types is
allowed if needed.

### F7 — Mail deep-dive (Mail tab)
Sections rendered as a list:
- Per MX host: A/AAAA, PTR of first A, FCrDNS verdict (PTR name resolves
  back to the same IP), formatted `mx host — ip — ptr name — FCrDNS ✓/✗`.
- MTA-STS: TXT at `_mta-sts.<domain>` (present + id), note that policy body
  is not fetched (HTTPS out of scope).
- TLS-RPT: TXT at `_smtp._tls.<domain>` (present + rua).
- BIMI: TXT at `default._bimi.<domain>` (present + l= URL).
- DKIM: for selectors found by the audit probe list, decode `p=` base64 and
  estimate RSA key bits (len*8 of modulus approximation: bits ≈
  (decoded_len - 22) * 8 rounded to 1024/2048/4096 buckets is overkill —
  report decoded byte length and flag < 128 bytes as weak-1024); note
  ed25519 (`k=ed25519`).

### F8 — Report export (key `e`)
`e` (outside popups) writes two files to the current directory:
`dnsdoc-<domain>-<YYYYmmdd-HHMMSS>.md` and `.json` — full dump of all tab
state (propagation rows, audit results, trace hops with NS, dnssec, mail,
sweep, monitor log, analysis diagnoses). Builder lives in new `src/report.rs`
as pure functions `render_markdown(&App) -> String` / `render_json(&App) ->
String` (serde_json::json! assembled — no new derives needed), unit tested on
a populated App. Status line shows the written paths or the error.

### F9 — SOA serial decode (Audit)
When serial parses as YYYYMMDDnn (year 1990–2035, month 01–12, day 01–31):
append `— date-encoded, zone last touched ~Nd ago` to the SOA sanity detail.
Pure fn + tests.

### F10 — HTTPS/SVCB + TLSA (Audit)
- HTTPS (type 65) at apex and `www.`: Ok listing params when present, Ok
  "none" otherwise (informational).
- TLSA at `_443._tcp.<domain>`: present → Ok with usage/selector/matching
  fields; absent → Ok "no DANE".

### F11 — Monitor latency sparkline
Monitor keeps the last 60 poll latencies per record type
(`App.monitor_latency: HashMap<String, VecDeque<u64>>`, pushed from a new
field on `Msg::MonitorSnapshot`). Snapshot lines gain a braille sparkline
(`▁▂▃▄▅▆▇█` buckets, pure fn `sparkline(&[u64]) -> String` + tests) and the
latest ms value.

### F12 — Subdomain sweep (Sweep tab)
Query A for a fixed candidate list (www, mail, smtp, imap, webmail, api, app,
dev, staging, test, vpn, remote, autodiscover, autoconfig, mta-sts,
_acme-challenge, ns1, ns2, cdn, shop, blog, docs, status, git) + AAAA/CNAME
for hits. Table: name — record — answer, streamed row by row (same
Msg-per-row pattern as propagation). Summary count in title. Wildcard
warning line when the audit's wildcard check hit (cross-check via a probe
query of a random label inline).

### F13 — Reverse lookup popup (key `v`)
`v` opens an input popup (reuse domain-input mechanics) accepting an IP.
Enter: PTR query (`x.x.x.x.in-addr.arpa` / nibble-format `ip6.arpa` for
v6 — pure `reverse_name(ip)` helper + tests), then forward-confirm the PTR
target. Result popup lists: PTR name(s), forward A/AAAA of each, FCrDNS
verdict. Esc closes.

## Infrastructure (batch 8, everything else builds on it)

`src/dns.rs`:
- `pub async fn raw_query_tcp(server, domain, rtype, rd) -> Result<(DnsResponse, u128)>`
  via `TcpClientStream` (hickory, same crate).
- `raw_query_opts` gains EDNS control:
  `pub async fn raw_query_edns(server, domain, rtype, rd, do_bit: bool) -> Result<(DnsResponse, u128)>`
  (sets `msg.extensions_mut()` OPT with DO flag + 1232 buffer). Existing
  `raw_query_opts`/`raw_query` unchanged in behavior.
- `pub fn reverse_name(ip: IpAddr) -> String` (in-addr.arpa / ip6.arpa).
- `rdata_to_string` arms for PTR, HTTPS/SVCB, TLSA, and the DNSSEC types
  (fall back to `other.to_string()` when typed variants are unavailable).
